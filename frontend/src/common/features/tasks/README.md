# Tasks

This feature owns reusable task transport types, staff-assignment contracts, and adapters consumed by Tasks and Timesheets. Pages own presentation and workflow composition; generic components and `ResourceCalendar` must not import this feature.

The canonical lifecycle, assignment, placement, deletion, authorization, presentation, and time-entry integration contract is [Assigned tasks](../../../../../docs/features/staff/tasks.md). Keep this README limited to local module ownership and usage constraints.
