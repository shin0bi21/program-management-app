# Frontend Pages

Start here when building or changing a route. Collection pages share a shell,
persisted controls, data views, and page-level messages. Authentication,
informational, and public pages keep the regions their task requires.

| Task | Guide |
|---|---|
| Order page setup, load data, coordinate filters, and compose the shell | [Page Composition](composition.md) |
| Save controls and recover stale selections | [Page Preferences](preferences.md) |
| Verify page-owned behavior and child coordination | [Page Testing](testing.md) |
| Generate a page and colocated implementation/test owners | [Page Scaffolding](scaffolding.md) |

Keep page-specific code beside its route. Follow [Frontend Ownership](../architecture/ownership.md)
for directory boundaries and [Components](../components/README.md) for shared surfaces.
